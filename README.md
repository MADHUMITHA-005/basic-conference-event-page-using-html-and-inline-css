# Conference Website

A simple conference webpage built using HTML for practice and learning purposes.

## About the Project

This project is a basic conference website created to practice HTML by structuring webpage content and organizing information related to a conference.

## Features

* Conference information and details
* Structured webpage layout
* Organized content sections
* Simple navigation structure

## Technologies Used

* HTML5

## What I Learned

* Structuring webpages using HTML.
* Using headings, paragraphs, links, and other HTML elements.
* Organizing content into meaningful sections.
* Building a basic website from scratch.

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open the HTML file in your browser.
